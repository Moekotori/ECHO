# ECHO NEXT Community 26.9.28

本次更新重点改善大曲库浏览、后台播放的资源占用，以及界面恢复时的播放连续性。社区版永久免费，采用 AGPL v3 开源协议，DSP 音效功能也可免费使用。

## 性能与 Ultralight

- 社区版加入可选的 Ultralight 模式：满足条件时，最小化或收进托盘可释放主界面，由原生音频宿主继续播放；重新打开后恢复界面与播放状态。
- 修复 Ultralight 进入／退出并发、旧恢复计时器、重复歌曲队列和任务栏恢复窗口的问题，改善后台播放控制及自动续播。
- 恢复界面或重新加载界面时，读取宿主当前的音量、倍速、DSP 和播放进度，避免初始化设置覆盖正在播放的状态。
- 歌曲列表直接加载当前滚动位置所需的分页，合并快速滚动请求，并按实际行高定位，减少大曲库向下滚动时长时间显示骨架占位的问题。
- 将曲库查询移到独立工作线程，优化重复曲目查询、历史记录和统计计算，减少这些操作对主进程与播放控制的阻塞。
- 歌词界面隐藏时释放相关资源，并改善后台窗口、封面和流媒体缓存的内存使用。

## 播放与曲库

- 修复随机播放在原生队列自动续播时的顺序处理，改善播放历史更新。
- 更新 Windows 任务栏播放按钮图标与播放顺序控制，改善托盘／任务栏的后台操作。
- 改善歌曲列表跨分页选择、正在播放曲目定位，以及刷新与滚动同时发生时的位置保持。
- 加入专辑拆分工具，改善专辑艺术家归类及相关曲库界面。

## 歌词、MV 与界面

- 改善歌词和 MV 匹配：结合封面信息判断候选版本，优化候选去重、排序与搜索请求。
- 改善 MV 自动选择设置变更后的重试行为；左下角封面支持进入 MV 界面。
- 完善歌词时间调整、界面操作与设置说明，并更新多语言内容。
- 改善 Scoop 安装识别、更新处理及便携版数据目录行为。
- 修复开发环境中原生 SQLite ABI 检查与依赖加载问题。

## 下载与兼容性

- Windows x64：提供安装版 `ECHO-NEXT-Setup-26.9.28.exe` 与便携版 `ECHO-NEXT-Portable-26.9.28.exe`。
- Windows 包沿用社区版的未签名发布方式，系统可能显示未知发布者提示；请从本仓库的 Releases 下载。
- Ultralight 默认关闭，原生输出和可由宿主接管的本地队列满足条件时才会释放主界面；CUE、远程曲目及不兼容输出会保留常驻界面。禁用 GPU 的选项也默认关闭。
- 大曲库加载耗时仍受磁盘、数据库大小和筛选条件影响，本次优化不代表所有滚动位置都能瞬时加载。
