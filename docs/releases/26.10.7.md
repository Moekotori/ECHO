# ECHO NEXT Community 26.10.7

本次更新修复普通本地音频导入、扫描后，后台 BPM 分析自动改写原文件的问题。建议使用 26.10.3 及更早版本的用户更新。

## 源文件完整性修复

- BPM 分析结果只保存到曲库数据库，不再自动写入原音频标签。
- 移除后台标签写入的延迟重试，避免扫描结束后继续改写文件。
- 修复这条自动写回链路造成的整文件 SHA-256 变化及内嵌歌词丢失问题。
- 旧版本已经删除的歌词需要从原件或备份恢复；升级不会自动恢复已丢失的歌词。

## 验证

- 111 个定向用例通过，包括曲库服务集成测试和元数据、扫描、分析器回归测试。
- 两首真实 FLAC 的隔离副本在两种扫描器下，经过重复导入、增量扫描、重读标签、自动 BPM、强制 BPM 和 ReplayGain 分析后，SHA-256、歌词、文件大小和修改时间均保持不变。
- FLAC、MP3、M4A、WAV、OGG、OPUS、AIFF 的生成样本在导入、扫描及分析后，SHA-256 均保持不变。

## 下载与兼容性

- Windows x64：安装版 `ECHO-NEXT-Setup-26.10.7.exe`、便携版 `ECHO-NEXT-Portable-26.10.7.exe` 和 ZIP 包 `ECHO-NEXT-26.10.7-win.zip`。
- 安装版自动更新读取本 Release 的 `latest.yml`；便携版需要手动替换。
- Windows 包沿用社区版的未签名发布方式，请从本仓库 Releases 下载。
- 本次未构建 macOS 或 Linux 包。
