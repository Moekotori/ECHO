# ECHO NEXT Community 26.10.3

GitHub Releases 上一个可自动更新的 Windows 包是 26.6.24。本版版本号高于 26.6.24 和 26.9.28，安装版会从官方 GitHub 更新源收到这次更新。

## 流媒体、下载与 MV

- 移除音乐流媒体服务，包括在线搜索、在线播放和流媒体歌单导入。
- 移除歌曲下载、osu! 下载，以及专辑、歌单、播放器上的下载入口。
- 保留 MV。账号页保留哔哩哔哩登录，用于需要账号的 MV；公开 MV 不登录也可以搜索和播放。
- 本地曲库、本地播放、歌词、Echo Pro、Last.fm 和 Discogs 仍可用。

## 自上一份 GitHub 安装包以来的其它变化

- 大曲库浏览、后台播放和 Ultralight 模式的性能改进见 26.9.28 说明。
- 歌词可以匹配带语言标记的旁路歌词文件。
- 壁纸支持竖图和透明度。

## 下载与兼容性

- Windows x64：安装版 `ECHO-NEXT-Setup-26.10.3.exe`，便携版 `ECHO-NEXT-Portable-26.10.3.exe`。
- 自动更新读取该 Release 里的 `latest.yml`，只作用于安装版。便携版不会走这套自动安装。
- Windows 包沿用社区版的未签名发布方式，系统可能显示未知发布者提示。请从本仓库的 Releases 下载。
- 本次没有重新构建 macOS 包。
