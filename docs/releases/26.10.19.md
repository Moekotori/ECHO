# ECHO NEXT Community 26.10.19

本次更新主要改进大曲库、CUE 导入、本地歌词和播放器界面。

## 曲库与导入

- 限制大批量扫描、BPM 和 ReplayGain 分析的任务队列，减少大曲库后台处理时的内存占用。
- 改进缺失文件检查、重复项维护和搜索索引处理，减少长任务对界面操作的影响。
- 修复导入完成后的旧状态回写问题，避免新导入的曲目被回退。
- 改进 CUE 分轨导入、关联音频识别和格式筛选，减少整轨与分轨重复出现的问题。
- 改进封面读取、失败重试和缓存，减少重复读取与无效预加载。

## 歌词与播放

- 扩展本地歌词格式支持，包括 KRC、SRT、VTT、ASS、SSA、TRC、LRCX 和 SNC；继续支持带语言后缀的歌词附件。
- 将歌词罗马音处理放到独立进程，改进日文搜索与文本转换缓存。
- 改进歌词页迷你播放器的自动隐藏，以及页面返回、封面和歌词控件的交互。
- 修复 Automix 混入下一首时未正确应用主音量的问题。
- 将 FFmpeg 路径检查改为异步处理，减少播放准备阶段对主进程的阻塞。

## 界面

- 调整侧栏分组、播放器按钮、歌单封面墙和主题样式。
- 改进歌曲与专辑筛选、排序及页面滚动位置保留。

## 下载与更新

- Windows x64：安装版、便携版和 ZIP 包。
- 安装版开启自动更新并使用官方源时，可在应用内检测、下载并安装本版；更新前会检查播放、扫描、标签写入和备份任务。
- 便携版仍需手动替换；本次未构建 macOS 或 Linux 包。
- 沿用社区版的未签名发布方式，请从本仓库 Releases 下载。
- 流媒体、歌曲下载和 osu! 下载页面仍不在社区版中开放。
- 导入、扫描与自动分析继续只读原始媒体文件，分析结果只存入曲库或缓存。
