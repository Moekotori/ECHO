# ECHO Next 26.7.18 更新日志


> [!WARNING]
> **这是一次改动范围非常大的版本更新。**
>
> 我们重做了播放器底层、专业音频输出、曲库扫描、设备切换和多项跨设备能力。新功能很多，新的 Bug 也可能很多。建议更新前备份重要数据并保留上一版本安装包；如果遇到无法播放、爆音、设备失联、曲库异常或明显性能问题，请及时反馈，必要时先回退到上一稳定版本。用户可以选择性更新，如果您担心稳定性 请继续使用26.7.1稳定版

## 一句话版本

这次把 ECHO 的播放器心脏、专业音频链路完全重构了一遍：播放更原生，DSD / ASIO 更完整，切歌更连贯，手机也能直接遥控；同时歌词、MV、曲库、设置和低配设备体验都得到了大幅改进。

## 播放器底层大升级

- 本地 PCM 播放、格式转换和更多 DSP 工作已迁移到独立的原生音频进程，减少界面卡顿、后台任务或单个模块异常对播放的干扰。
- 新增无缝播放准备与自动切歌链路，换歌时会提前准备下一首，减少曲目之间不必要的停顿。
- 智能转场进一步升级，可结合节奏分析规划衔接，并尽量保持在原生输出链路中完成。
- 修复手动停止后仍可能跳到下一首、智能转场意外重新开始播放、切换输出后会话状态不同步等问题。
- 调整播放进度刷新、后台视觉效果和启动时封面加载策略：窗口不活跃时少做无用功，播放优先。
- 新增更可靠的 True Peak 峰值保护与高阶 SDM 噪声整形，降低复杂 DSP 或高规格输出下的削波与异常噪声风险。

## DSD、ASIO 与专业输出

- 新增并完善 ASIO 与 Windows 独占输出，输出设备、模式和实际信号路径显示更加准确。
- 支持原生 DSD / DoP 播放链路，并扩展至 DSD512、DSD1024 直通能力；实际可用规格仍取决于 DAC、驱动和连接方式。
- 修复 ASIO 原生 DSD 路由、输出设备记忆、设置页设备同步及多种输出模式切换问题。
- 加强设备拔插、占用释放、一次性输出所有权和异常退出处理，降低设备切换后无声、卡住或无法重新打开的概率。
- 当独占输出不可用时，可提供 DirectSound 回退和更清楚的状态提示，避免只留下一条难懂的错误信息。

## GPU 加速，但不盲目迷信 GPU

- 原生音频核心现已具备 CUDA FIR 加速能力，并会根据滤波器长度和实际性能判断是否值得启用。
- 长 FIR / 高倍率房间校正可在合适的 NVIDIA GPU 上获得明显加速；很短的 FIR 仍可能由 CPU 更快完成，因此不会为了“显示启用了 CUDA”而强行走显卡。
- CUDA SDM 已进入实验和实时准入体系；如果当前设备无法稳定实时运行，ECHO 会保守回退到 CPU，而不是冒险造成卡顿或爆音。
- 增加 CUDA 状态、准入结果和回退原因诊断，方便高级用户确认“显卡是否真的在干活”。

## ECHO Link：手机变成真正的遥控器

- ECHO Link Basic 新增同一局域网内的移动遥控页面，无需额外安装 App，即可在手机上查看和控制当前播放。
- 重新设计移动端播放控制，优化进度更新、初始播放状态、封面与曲目信息展示。
- 新增 “Everything Connected” 播放交接能力，为桌面端、移动端和其他接入端之间的状态同步打下基础。
- 远程音频播放现已进入原生音频进程，支持 HTTP 音源、启动握手和更可靠的进度回传。
- Connect / AirPlay / DLNA / ECHO Link 相关服务改为按需加载，减少不使用这些功能时的启动负担。

## 歌词、迷你播放器与 MV

- 同步歌词重新支持点击跳转：只在时间有效、播放状态允许且当前链路安全时执行，避免误跳和重复跳转。
- 新增歌词迷你播放器快捷键开关与浅色模式，并修复首次打开时的方块闪烁、尺寸变形和文字不可读问题。
- 歌词匹配、候选列表和设置抽屉重新布局，信息更清楚，操作更集中。
- MV 自动搜索与匹配逻辑升级，改进置信度、搜索词和视频重新挂载行为，并加入 Bilibili 兜底搜索。
- 播放栏、歌词页和 MV 页面之间的布局切换更平滑，减少第一次进入时的跳动。

## 曲库与封面

- 曲库扫描进一步后台化、并行化，并优化大曲库搜索、身份识别、元数据读取和封面提取流程。
- 实验室新增原生文件扫描器开关。实测在大型文件列表中有明显提速，但仍保留原有扫描路径作为默认和回退方案。
- 原生元数据读取仍属于实验功能；在现阶段测试中并非总是更快，因此默认不启用。
- 优化内嵌封面缓存和元数据比较，减少重复读取、重复写入以及同一封面被反复处理。
- Navidrome 等远程曲库会更积极复用封面缓存，并对远程音频与封面缓存设置合理上限。
- 新增按编码、音频规格、比特率和 BPM 排序，查找高规格或特定类型曲目更方便。
- 改进文件删除、NCM 转换、扫描清理及异常数据保护，降低曲库操作误伤其他记录的概率。

## 远程曲库与连接体验

- WebDAV、Subsonic / Navidrome、百度网盘、SMB、SSHFS 等远程来源采用统一的连接流程。
- 连接、授权、同步和高级参数现在使用同一套界面，不再点击“开始连接”后突然回到旧版表单。
- 优化远程同步分批处理、封面加载、网络请求重叠和离线授权宽限，弱网或大曲库下更从容。
- 远程流媒体播放会保留更完整的来源和曲目信息，系统媒体面板、历史记录和播放状态更一致。

## 界面、设置与低配设备

- 设置页重新整理为更容易导航的工作区，账号、音频、快捷键和实验功能不再挤在一起。
- 快捷键绑定界面重新设计，并修复筛选条件与用户配置互相影响的问题。
- 新增保守的低配置模式，减少后台视觉刷新和不必要的高开销任务。
- 侧边栏支持编辑入口与折叠，专辑预览、文件夹详情、播放队列和历史页面也做了响应式调整。
- 播放错误现在会直接显示为应用内提示，不必再从日志里猜发生了什么。
- Windows 系统媒体控制（SMTC）同步更稳，远程封面下载增加大小、超时、类型和地址安全限制。
- Discord、Last.fm、Stage、Wallpaper Engine 等集成开始共享更一致的播放状态基础，后续扩展会更容易。

## 安装、更新与安全

- 加强 Windows 安装包签名和完整性检查，修复签名产物、打包后错误信息丢失等问题。
- 更新安装改为明确授权后执行，减少后台意外触发安装的风险。
- Windows 环境检查、镜像配置和依赖准备流程得到改进，并固定 Node / npm 版本以减少环境差异。
- 账号敏感信息改进加密存储；远程封面、缓存和外部请求也增加了更严格的边界。
- Windows 安装包补齐 yt-dlp 和精简版 FFmpeg 支持，MV 与媒体解析开箱体验更完整。

## 已知风险与反馈建议

本次更新同时触及音频设备、原生进程、曲库数据库、远程播放和界面状态，组合情况非常多，我们无法保证已经覆盖每一种声卡、DAC、驱动、GPU 和曲库结构。

如果遇到问题，反馈时最好附上：

- 出问题前执行了什么操作，例如切换 ASIO、拔插 DAC、点击歌词、开始扫描或手机接管播放；
- 当前输出模式、设备型号、驱动类型，以及是否启用了 DSP、DSD、CUDA 或实验室功能；
- 问题是否可以稳定复现，重启 ECHO 后是否恢复；
- 应用版本、错误提示、日志或一小段录屏。

如果出现持续爆音、音量异常、设备反复占用、曲库大量丢失或应用无法启动，请先停止继续操作，退出新版并回退到上一稳定版本，再把现场信息反馈给我们。稳定和数据安全永远比“硬撑着用新功能”更重要。

感谢每一位愿意试用、反馈和折腾 ECHO 的用户。这个版本可能不够完美，但它让 ECHO 离我们想做的那台“真正懂音乐，也懂设备”的播放器近了一大步。
