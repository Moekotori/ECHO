# 本地歌词与编辑

支持 LRC、TTML、YRC、可读文本/XML QRC、KRC、SRT、VTT、ASS、SSA、TRC、LRCX、SNC 和 TXT。加密 QRC 容器不在支持范围内。

本地外挂继续沿用现有的同名文件、`lyrics/` 子目录、语言后缀及翻译/罗马音附件匹配。也可以在歌词页导入或拖入文件，或者在歌曲标签窗口的“歌词”分区预览、编辑并保存到歌词库。修改歌词库不会自动嵌入源音频文件；嵌入仍需单独执行。

字幕格式只读取正文与时间，ASS/SSA 的样式、绘图、位置和动画不会进入界面。LRCX 的翻译和读音按现有行级字段显示。损坏的同步格式导入会报错，外挂查找会跳过无效文件。LRC/TXT 保留原有纯文本兼容行为。

沿用单文件 2,000,000 字节、文本 1,000,000 字符、2,000 行、单行 2,000 字符、单行 160 个逐词片段限制；KRC 的解压输出同样受大小限制。解析模块从 ECHOSteam 的独立实现迁入，未引入新依赖。
